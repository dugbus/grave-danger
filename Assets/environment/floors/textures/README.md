# FloorSurface texture library

These game-owned texture copies are available to reusable `FloorStyle` resources.
The source textures under `Assets/environment/` remain in place so existing levels and
materials keep their original references while FloorSurface is developed independently.

Add new floor textures here, then reference them from a `FloorStyle` resource in
`addons/floor_surface/` or from a future game-owned style library.
