# Godot best practices — Codex edition

A retrieval-friendly export of the Godot best-practices documentation.

## Optimisations

- One topic per Markdown file.
- GDScript examples retained; parallel C# and C++ examples removed.
- Navigation, user-note boilerplate, and inline link targets removed.
- Normal Markdown code fences and compact whitespace.
- Original page URL retained as an HTML comment in each file.

## Suggested Codex use

Point Codex at this directory rather than injecting the combined document.
Ask it to read only the topic files relevant to the current task.

Example instruction:

```text
Consult docs/godot-best-practices only when relevant.
Read the smallest number of topic files needed for the task.
Treat these files as guidance, not project-specific requirements.
```
